API = Application Programming Interface

API is a way for two software application to communicate each other

client side ==> it runs on the user's device (chrome, edge, firefox, mobile application, windows application)
server side ==> that runs on the server and handle the business logic (java/spring boot, node.js, python, .net)
Database ==> stores the data

browser --> API (login request) --> server side --> "let me check this user" --> user found --> server side --> API response -->  browser

//status code
for your request server send response

//1XX --> Infotmation (not in testing) (100-199)
//2XX --> Success (200-299)
//3XX --> Redirect (300-399)
//4XX --> Client Error (400-499)
//5XX --> Server Error (500-599)

//2XX - Success

200 - OK
201 - Created (new resources/data are successfully created)
202 - Accepted server accept your request but response may take time 
204 - No Content (the request was successful, but there no response)

//3XX - Re-diretion

301 - moved resource (the resource permently moved to another URL)
302 - temporary redirect

//4XX
400 - Bad Request
401 - Unauthorized Problem (Invalid Credentials and tokens)
402 - Payment Required
403 - Forbidden (Permission) Bearer token
404 - Not Found
405 - Method not allowed 
408 - Request Timeout
409 - Conflict (Duplicate)

5XX

500 - Internal server error (application bug, unhandled exception, cofiguration)
501 - Not Implemented
502 - Bad Gateway
503 - Server unavailable (maintanace, overloaded maintanace)
